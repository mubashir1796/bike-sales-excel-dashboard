# Bike Sales Excel Dashboard

## Overview

This project focuses on exploring and analysing a bike sales dataset using Microsoft Excel.

The dataset contains information about 1,000 customers, including their gender, income, education, occupation, number of children, home ownership, number of cars, commute distance, region, age, and whether they purchased a bike.

The main purpose of the project was not just to create a dashboard, but to work through the full process of preparing and understanding the data first.

## Project Process

I started by exploring the original dataset to understand the different variables and the type of information available.

The next step was data cleaning. I made some of the categories more consistent and easier to read and work with. I also created an additional **Age Brackets** column using Excel formulas to group customers by age.

After cleaning the data, I used pivot tables to explore different patterns in the dataset. I looked at differences between customers who purchased a bike and those who did not, with a focus on gender, age, income, and commute distance.

The final step was to bring the main findings together in an Excel dashboard.

## Dashboard

The dashboard is titled **Bike Sales Dashboard** and presents three main views of the data:

- Average income by gender and bike purchase status
- Customer distribution across age brackets
- Customer commute distance by bike purchase status

The purpose of the dashboard is to make the results easier to compare and understand without having to go through the full dataset.

## Excel Work

Some of the main Excel tasks used in this project include:

- Data exploration
- Data cleaning
- Creating new categories using formulas
- Pivot tables
- Data analysis
- Data visualization
- Dashboard creation

## Main Questions Explored

The project looks at questions such as:

- How does average income differ between customers who purchased a bike and those who did not?
- How does bike purchasing vary across different age groups?
- How does commute distance relate to bike purchasing?
- Are there noticeable differences between male and female customers in the data?

## Project Outcome

This project helped me practise the complete process of working with data in Excel, starting from raw data and moving towards a finished dashboard.

The biggest learning for me was that a dashboard is only the final part of the process. Before building the visuals, the data needs to be understood, cleaned, organised, and analysed properly.
